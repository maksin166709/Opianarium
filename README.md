# Opianarium v2.2: как выложить в открытый доступ

В папке всё нужное: `index.html` (приложение), `sw.js` (автообновление и работа без интернета),
`manifest.webmanifest` и четыре иконки. Загружать нужно ВСЕ файлы.

## 1. Открытый доступ (бесплатно, GitHub Pages)
1. Зарегистрируйся на github.com.
2. New repository → имя `opianarium` → Public → Create.
3. Add file → Upload files → выбери все файлы из папки → Commit changes.
4. Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)` → Save.
5. Через 1–2 минуты появится ссылка вида `https://ТВОЙ-НИК.github.io/opianarium/`.
   Её можно отправлять кому угодно.

Другие варианты: Netlify Drop (app.netlify.com/drop) или Cloudflare Pages. Подойдёт любой
хостинг статических файлов с https.

## 2. Установка как приложение (без APK)
Открой ссылку в Chrome на Android → меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).
Иконка появится на экране, приложение откроется без адресной строки.

## 3. APK-файл
1. Зайди на pwabuilder.com и вставь ссылку на сайт → Start.
2. Package for stores → Android → Generate package.
3. Скачай архив: внутри `.apk` и файл ключа подписи. Ключ сохрани, он понадобится для будущих обновлений APK.
4. Для установки APK на телефоне разреши установку из неизвестных источников.

APK открывает твой сайт, поэтому содержимое обновляется само, пересобирать APK под каждую версию не нужно.

## 4. Как работает автообновление
Приложение каждый раз сначала берёт свежие файлы с сайта и только без интернета открывает сохранённую копию.
Когда ты заменяешь файлы в репозитории на новые, у всех пользователей новая версия появится при следующем
открытии (или сама, если приложение уже открыто). Чтобы выпустить обновление, загрузи новые `index.html` и `sw.js`
поверх старых.

## 5. Важно
- Данные (траты, обои, баннер, аватарка, имя) хранятся на устройстве каждого человека отдельно.
- Адрес сайта отличается от адреса в Claude, поэтому старые данные не перенесутся сами:
  в Claude-версии ⚙ → Резервная копия → «Показать копию», скопируй текст, на новом адресе
  ⚙ → Резервная копия → вставь и нажми «Восстановить из текста».
- Помощник в чате работает только внутри Claude, в публичной версии его карточка скрыта.
- Для новых пользователей стартовые разделы: Еда, Транспорт, Прочее.

## 6. Что нового в v1.9
- Три языка: русский, украинский, английский. При первом открытии выбирается по языку телефона, менять можно в ⚙ → Язык.
- 14 валют: основная валюта выбирается в ⚙ → Деньги → Валюта. Там же можно показывать суммы в другой валюте по своему курсу.
- При первом открытии все эффекты (дождь, туман, молнии, наклон, звук) выключены. Включаются в ⚙ → Дождь и стекло.
- У тех, кто уже пользовался приложением, язык, валюта и эффекты остаются как были.
- Чтобы обновить сайт, загрузи в репозиторий новые `index.html` и `sw.js` поверх старых.

## 7. Что нового в v2.0
- Новый интерфейс без бесконечной прокрутки: сверху закреплена шапка (аватарка, название, приветствие, ⚙), снизу панель вкладок.
- Вкладки: «Бюджет» (сводка, параметры, разделы), «Аналитика» (график, история, повторяющиеся расходы, итоги) и «Помощник» (чат, работает только внутри Claude, в публичной версии вкладки нет).
- Настройки по-прежнему открываются поверх экрана по значку ⚙.
- Все расчёты и данные не менялись, обновление подтянется само.

## 9. Аккаунты: вход по email и паролю (v2.2)
Без настройки приложение работает как раньше, без входа. Чтобы люди заходили со своих аккаунтов с разных устройств,
нужен бесплатный облачный сервис Supabase (хранит аккаунты и данные):
1. На supabase.com создай проект (New project, бесплатный тариф).
2. Открой SQL Editor, вставь содержимое файла `supabase.sql` и нажми Run. Это создаёт таблицу и правила: каждый видит только свои данные.
3. Authentication → Providers: убедись, что Email включён. Если оставить «Confirm email», новым людям придёт письмо для подтверждения; если выключить, регистрация проще, но без проверки почты.
4. Authentication → URL Configuration: в Site URL вставь адрес сайта (например `https://ТВОЙ-НИК.github.io/opianarium/`), его же добавь в Redirect URLs. Нужно для писем подтверждения и сброса пароля.
5. Project Settings → API: скопируй Project URL и `anon public` ключ в файл `config.js` (между кавычками).
6. Загрузи в репозиторий `index.html`, `sw.js` и `config.js`.
После этого в ⚙ появится раздел «Аккаунт»: регистрация, вход, сброс пароля, синхронизация и выход.

Важно:
- Ключ `anon public` можно держать в `config.js`, он публичный по задумке. Защищают данные правила из `supabase.sql`. Ключ `service_role` в приложение вставлять нельзя.
- Синхронизируются траты, разделы, имя, аватарка, баннер и язык. Обои и эффекты остаются на каждом устройстве свои.
- При входе на новом устройстве данные подтягиваются из облака. Если на этом устройстве уже есть свои, приложение спросит, что оставить.
- При выходе данные с устройства удаляются (они остаются в облаке), чтобы следующий человек не увидел чужое.
- Это финансовые данные других людей, а хранишь их ты через свой проект Supabase. Пользователям стоит сказать, где лежат их данные. Лимиты бесплатного тарифа, в том числе на письма и «засыпание» проекта при долгом простое, проверь на сайте Supabase.
